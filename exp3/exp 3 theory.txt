EXP 3 THEORY: CLIENT-SIDE PROGRAMMING WITH JAVASCRIPT

1. INTRODUCTION TO JAVASCRIPT
JavaScript (JS) is a high-level, interpreted scripting language that conforms to the ECMAScript specification. It is the primary language used to add interactivity and dynamic behavior to web pages. Unlike HTML (structure) and CSS (presentation), JavaScript handles the "behavior" of the web application.

Key Features:
- Client-Side Execution: Code runs in the user's browser, reducing server load.
- Event-Driven: Responds to user actions like clicks, scrolls, and keypresses.
- Dynamic Typing: Variables can hold different data types without explicit declaration.

2. DOCUMENT OBJECT MODEL (DOM)
The DOM is a programming interface for web documents. It represents the page so that programs can change the document structure, style, and content. The browser treats the HTML document as a tree of nodes.

- Accessing Elements: Methods like document.getElementById("id"), querySelector(), and getElementsByClassName() are used to select HTML elements.
- Modifying Content: The innerHTML or textContent properties allow developers to dynamically update the UI (e.g., displaying a "Welcome" message).

3. FUNDAMENTALS OF JAVASCRIPT LOGIC
To build functional applications (like a Bookstore), various programming constructs are used:

A. Data Types and Variables
Variables are containers for storing data values. Common types include:
- String: Textual data (e.g., Book Title).
- Number: Integer or floating-point values (e.g., Price).
- Boolean: Logical entities representing true or false (e.g., In-Stock status).

B. Operators
Operators are used to perform operations on variables and values.
- Arithmetic Operators: +, -, *, / for calculations like total bill.
- Comparison Operators: ==, ===, >, < for logic checking.
- Logical Operators: && (AND), || (OR), ! (NOT).

C. Control Flow (Decision Making)
Control structures determine the flow of execution based on conditions:
- If-Else: Used for binary decisions (e.g., applying a 10% discount if the total exceeds 1000).
- Switch Case: Efficiently handles multiple discrete options (e.g., navigating between "Programming," "Novel," or "Kids" sections).

4. COLLECTIONS AND REUSABILITY
A. Arrays
Arrays are used to store multiple values in a single variable. They are essential for managing lists of items, such as a catalog of books or a shopping cart.
- Properties: length helps track the number of items.
- Methods: push() adds items to the end of the list.

B. Loops
Loops (like for and while) allow repeating a block of code. They are used to search for items in an array or to iterate through a cart to calculate the final amount.

C. Functions
Functions are blocks of code designed to perform a particular task. They promote code reusability and modularity (e.g., a dedicated addToCart() function).

5. CLIENT-SIDE VALIDATION (CO3 Implementation)
The concepts mentioned above--DOM manipulation, control flow, and data types--are the building blocks of Client-Side Validation.
- Logic: Using if-else to check if input fields are empty or if a numeric value is within a valid range.
- Feedback: Using DOM methods to display error messages instantly without refreshing the page.
- Efficiency: Validating on the client side provides immediate feedback to the user, improving User Experience (UX) and reducing unnecessary server-side processing.
